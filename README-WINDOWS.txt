Practice Machine by SHY — Windows版 설치/사용 안내
====================================================

[요구사항]
- Windows 10/11 (64비트)
- RAM 16GB 권장 (8GB는 스텝 분리가 느려질 수 있음)
- 인터넷 연결 (첫 설치 시 PyTorch 등 수백 MB 다운로드)

[설치 — 딱 한 번]
1. 이 폴더 전체를 원하는 위치에 압축 해제 (문서/바탕화면 아무 곳이나)
2. INSTALL.bat 더블클릭
   - Python이 없으면 자동으로 설치를 시도합니다 (winget)
   - 첫 설치는 몇 분 걸립니다 (PyTorch 다운로드)

[매번 사용]
- START.bat 더블클릭 → 서버 시작 + 브라우저 자동 오픈
- STOP.bat 더블클릭 → 서버 종료
- 노래 추가: 화면 상단에 YouTube URL 붙여넣기

[폰·태블릿에서 부르기 (같은 와이파이)]
- TOGGLE_EXTERNAL.bat 더블클릭 = 켜기/끄기 전환
- 켜면 팝업에 표시되는 http://아이피:8011 주소로 폰 브라우저에서 접속
- 첫 켜기 때 "Windows 보안 알림(방화벽)"이 뜨면 [허용]을 눌러주세요

[완전 삭제]
- UNINSTALL.bat 더블클릭 — 런타임/곡데이터/폴더를 하나씩 물어봅니다
  (엔터만 누르면 안전한 기본값: 곡 데이터는 남김)

[처음 실행 시 주의]
- "Windows가 PC를 보호했습니다" (파란 화면) 가 뜨면:
  [추가 정보] → [실행] 버튼을 누르면 됩니다 (서명되지 않은 무료 앱이라 뜨는 것)

[참고]
- 스템 분리는 곡당 몇 분 걸릴 수 있습니다 (백그라운드 처리 — 기다릴 필요 없음)
- 로그 확인: VIEW_LOG.bat (문제가 생기면 backend\run.log, backend\run.err 참고)
- 본 프로그램은 개인 연습 목적의 도구입니다. 사용자는 각자 관할 법률과
  플랫폼 약관을 준수할 책임이 있으며, 다운로드한 음원의 권리는 원 저작권자에게 있습니다.
